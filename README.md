# 名窩居室內設計網站 · Regal House

香港裝修及訂造傢俬公司形象網站，使用 HTML、CSS 及 JavaScript 製作。

## 網站內容

- 公司及服務介紹
- 設計理念及服務流程
- 過往案例文字展示區（項目資料待補充）
- 門市資料與 WhatsApp 查詢表格

## 預覽及發布

本機可直接開啟 `index.html`。GitHub Pages 可使用 `main` 分支的根目錄作為發布來源，無須建置步驟。亦可把網站檔案直接上傳到 Cloudflare Pages。

## 圖片及查詢

首頁室內圖片為 AI 製作的設計示意圖，非實際完工案例。公司 Logo 由公司提供。

查詢表格會開啟 WhatsApp 並預填內容，由訪客自行確認發送；本站不儲存表格資料。
